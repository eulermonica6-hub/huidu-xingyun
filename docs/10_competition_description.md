## 一、作品名称

**慧读星云：基于AI知识图谱的《星云大师全集》人间佛教智能研析与知识服务平台**

## 二、作品简介（限 2000 字以内）

**开发背景。** 高校图书馆的特色馆藏普遍面临"数字化后却藏而难用"的困境：全文可以检索，但读者无法获得结构化的知识与可追溯的原文证据。《星云大师全集》体量庞大、术语密集，人物、经典、教义、实践、机构、地点彼此以稳定关系交织，正是这类困扰的典型：一篇文献是否谈"共生"、两部经典之间如何关联、"大师"究竟指谁，检索框都答不上来。

**核心痛点。** 一是通用大语言模型会"一本正经地编造"语料事实，且无法回链原文；二是传统关键词检索只能命中字面，无法理解语义与关系，回答不了"《维摩经》如何连接到人间佛教实践"这类问题；三是图谱与全文割裂，读者难以在"权威知识"与"原始文本"间来回跳转；四是缺少证据分级，稳定事实与语境解读混为一谈。

**技术路线。** 系统采用"一个主编排器 + 多类受控工具"而非多智能体自由协商，兼顾稳定与可解释：LangChain 负责模型适配、工具接口与消息对象，LangGraph 负责意图分类后的条件路由、并行检索、重试与答案审校。系统先识别 11 类一级意图，再路由到七条执行路线——图谱直接查询、图谱与全文混合推理、全文检索回答、LLM 直接回答、图谱计算分析、专题研究流程，以及澄清或拒答；路由后只向模型暴露当前流程所需的最小工具集，避免误选。领域内容能由工具与数据确定的部分绝不交给模型凭空生成。

**创新举措。** 其一，建立 A/B/C/D 四层证据体系——稳定关系及原文（A）、语境命题（B）、全文线索（C）、一般知识（D），回答逐句标注依据与出处，并从数据层面确保「大师」这一称谓不被自动等同于「星云大师」本人。其二，构建覆盖 20,020 篇文献的语义向量检索，以"图谱高精度 + 全文高召回"双检索策略弥补纯图谱召回不足。其三，逐句证据审校作为质量门控，审校不通过时自动降级为证据摘要，绝不让模型补造语料事实。其四，在证据不足时显式暴露覆盖边界，Claim 恒定以限定语表达，不越层。其五，密钥不入工程、模型角色可替换、索引只写派生目录，支持离线打包与本地部署。

**应用场景。** 面向宗教学/人间佛教研究者、馆员与本科研究生，提供可信问答（结论＋关系路径＋原文证据＋不确定性提示）、关系探索（实体子图与多跳路径）、原文检索（语义定位出处）、专题阅读路线（如"人间佛教与现代教育"），并预留馆员复核入口作为图谱治理的受控通道。

## 三、实施成效与推广价值（限 1000 字以内）

**数据底座（冻结口径）。** 平台构建于 20,020 篇全集正文、105 册书目之上，形成 25,560 个实体、153 种关系类型、2,748 条稳定关系、3,514 条稳定证据、4,250 个语境命题及其证据链；每条稳定关系回链原文段落与出处链接，全链路可追溯。

**质量底座（冻结口径）。** 稳定关系人工复核严格查准率 94.19%（语义支持口径 96.39%，样本 n=500）；语境命题忠实率 89.2%（样本 n=250）。系统路由、检索、生成、审校全程可记录、可测试。

**实施成效。** 已落地可运行的端到端闭环：意图路由 → 图谱/全文检索 → 证据融合 → 答案生成 → 逐句审校 → 结构化输出（答案、关系路径、原文证据卡、覆盖说明、后续操作）。对抗大模型"幻觉"与"事实越界"的关键机制均已生效。

**推广价值。** 本作品沉淀的"意图路由 + 知识图谱 + 全语文义检索 + 四层证据 + 逐句审校 + 馆员复核"方法论可迁移：只需替换为其他特藏或特色馆藏（方志、家谱、非遗、专题文库）的数据，即可复用同一平台框架激活馆藏资源。模型角色可按成本替换、检索可离线运行、密钥不入工程，适合高校本地化部署。
