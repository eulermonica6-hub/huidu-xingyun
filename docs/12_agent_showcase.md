## 关键能力点

1. **四层证据可区分**：A（稳定关系）/ B（语境命题）/ C（全文线索）/ D（一般知识），逐条 `[编号][层级]` 标注 + 出处 URL。
2. **证据边界显式暴露**：无直接关系/仅 C 层/无证据时，都如实说明，不「一本正经地编」。
3. **繁简/别名消歧**：原文提及优先于 LLM 提及，避免把唯一实体误判成歧义；「大师」≠「星雲大師」。
4. **逐句审校**：生成后逐句核验，最多自动修订一次；层级标签照抄、不得升降级。
5. **模型路由 + 回退**：快模型路由/审校，强模型推理，主模型失败自动切 zhipu 兜底。
6. **多轮指代**：REPL 中「它/该/此…」回指上一轮实体。
7. **证据包导出**：`--export` 生成 Markdown 证据包（结论 + 关系路径 + 证据卡 + 覆盖说明）。

## 已知边界（待优化）

- **端到端延迟偏高**：无 LLM 缓存时单问 ~30–90s（路由≈1s、语义≈1s、推理≈15–30s、审校≈5–15s、可能含一次修订）。证据截断已把 LLM 提示压到前 20 条；进一步可从「审校仅在 A/B 层触发」或流式输出入手。
- **高连接度实体证据量大**（如「星雲大師」→ 数十条稳定关系），已截断生成提示，但证据卡仍全量展示。
- **简体多义词**（如「人间佛教」）在数据里确为歧义别名，会主动澄清（属保护性行为，非故障）。
