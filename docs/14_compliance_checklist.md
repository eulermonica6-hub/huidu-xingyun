## 二、平台已具备（合规友好设计）

- **密钥不入工程**：真实密钥在仓库外 `../LLM api key.txt`，只解析具名条目、仅存内存；`.env` 不入仓、日志/异常/导出均脱敏。
- **源数据只读**：正文、图谱发布数据一律只读；切片/向量/缓存/日志只写 `data/derived/`、`runtime/`、`outputs/`。
- **生成内容可控**：四层证据 A/B/C/D + 逐句审校；回答附「覆盖说明」与「防御说明」，D 层（一般知识）明确标注不来自语料、提示自行验证。
- **审计可追溯**：`runtime/logs/audit.jsonl` 记录 route/意图/时延/重试/错误类型（不含密钥）。
- **权限最小**：无语料写接口、无任意 Text2Cypher、无账号/密钥接管面。
