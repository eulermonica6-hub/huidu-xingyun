# 项目章程

## 项目名称

慧读星云：基于AI知识图谱的《星云大师全集》人间佛教智能研析与知识服务平台

## 项目目标

将现有《星云大师全集》全文语料、可信知识图谱、Claim证据层和多维计算成果，转化为面向高校图书馆特色馆藏活化、研究支持与阅读服务的可访问智能体。

系统需要完成四件事：

1. 把自然语言问题路由到正确的检索或推理流程。
2. 让图谱关系、全文片段和LLM解释保持来源可区分。
3. 对领域性结论提供原文、篇章和图谱证据回链。
4. 在证据不足时明确暴露覆盖边界，不让LLM补造语料事实。

## 目标用户

- 人间佛教、佛学和宗教学研究者；
- 高校图书馆馆员；
- 本科生与研究生；
- 需要专题阅读和特色馆藏导航的普通读者。

## 第一版范围

- 实体解释；
- 直接关系查询；
- 一至三跳关系路径；
- 原文和出处检索；
- 知识图谱与全文混合解释；
- 四专题研析；
- 专题阅读路线；
- 证据导出与馆员反馈。

## 非目标

- 不自动修改正式知识图谱；
- 不把全文检索线索自动提升为稳定关系；
- 不把Claim节点混入稳定图中心性；
- 不承诺穷尽全集全部潜在语义关系；
- 不开放任意写操作或无限制Text2Cypher；
- 不在代码、日志或文档中保存API Key明文。

## 成功标准

- 每个领域答案可追溯到证据，或明确标注无充分证据；
- 路由、检索、生成和审校过程可记录、可测试；
- 公开演示系统可以稳定完成预设核心场景；
- 竞赛材料中的规模、精度和召回口径与冻结数据一致。
