# 操作指南（用户侧使用说明）

面向研究者、馆员与读者的「怎么用、怎么读懂结果」指南。安装与运维见 `docs/09_deployment_runbook.md`。

## 一、怎样提问

系统先把问题识别成 11 类意图，再路由到对应检索/推理流程。知道「问什么、怎么问」能拿到更稳的答案。

| 你想了解 | 建议问法 | 走哪条路线 |
|---|---|---|
| 两个对象的关系 | 「慈悲与教育是什么关系？」 | 图谱直查（graph_direct） |
| 概念/人物/经典解释 | 「什么是人間佛教？」 | 图谱+全文混合 |
| 多跳关联路径 | 「《维摩经》如何连接到人间佛教实践？」 | 图谱+全文混合 |
| 原文出处 | 「星云大师在哪些文章中谈到共生？」 | 全语文义检索 |
| 比较异同 | 「慈悲和般若在实践路径上有什么区别？」 | 图谱+全文混合 |
| 图谱结构/排名 | 「哪些概念在人间佛教网络中承担桥梁作用？」 | 图谱计算 |
| 专题阅读路线 | 「为“人间佛教与现代教育”设计一条阅读路线」 | 混合任务流 |
| 系统使用/帮助 | 「怎么使用这个系统？」 | LLM 直接回答 |

**提示**：优先用**繁体**实体名（如「人間佛教」「星雲大師」）可减少别名歧义触发澄清；简体某些词在库中是多义别名。

## 二、怎么读输出

一次回答由以下部分组成：

1. **直接结论** —— 先给结论，不啰嗦。
2. **关系路径** —— 若命中图谱，展示实体间的稳定关系链。
3. **原文证据** —— 每条带 `[编号][层级]`、卷册篇名、原文片段与出处 URL。
4. **解释与限制** —— 说明结论成立的前提与不确定处。
5. **覆盖说明**（见下）—— 明确证据可信度边界。
6. **后续操作** —— 「查看原文 / 展开子图 / 导出证据包 / 提交纠错」等可继续的动作。

### 覆盖说明（关键）

| 文案 | 含义 |
|---|---|
| 「结论基于：稳定关系（A 层）」 | 有正式图谱直接证据，最可信 |
| 「结论基于：语境命题（B 层…）」 | 属语境解释，已用限定语表达 |
| 「以下线索来自全文检索（C 层）…」 | 只是全文命中线索，尚未进正式图谱，谨慎采用 |
| 「当前…未检索到充分证据…」 | 明确无据，不硬答 |
| 「本回答…不来自《星云大师全集》语料」 | 一般性帮助，非领域结论 |

## 三、四层证据怎么读

| 层级 | 含义 | 可信度 | 示例 |
|---|---|---|---|
| **A** | 稳定关系 + 原文 | 高（正式图谱） | 「佛光山 —创立者→ 星雲大師」+ 原文出处 |
| **B** | 语境命题（Claim）+ 原文 | 中（需限定语） | 「在该语境中，大师将其解释为…」 |
| **C** | 全文检索线索 | 中低（未进图谱） | 语义/关键词命中的段落 |
| **D** | 一般知识 | 仅作背景 | 明确标注不来自语料 |

**核心理念**：能由图谱/原文确定的交给工具，需要归纳表达的才交给大模型；大模型不自己编造图谱事实。若答案改判了证据层级，说明被审校拦下或属异常（系统已加「层级标签照抄」约束）。

## 四、端到端示例

问：`星云大师在哪些文章中谈到共生？`

- 路由：`corpus_retrieve`（原文出处）
- 证据：8 条 `[C]` 全文线索，来自语义向量召回 + 关键词精排
- 回答要点：列出具体篇名（《佛法滿人間》<同體共生>、《雲水日月》<共生吉祥>、媒体专访标题<世界本來同體共生>），并**明确哪些只是标题/转述、不构成大师本人陈述**
- 覆盖说明：C 层提示

## 五、导出与反馈

- **导出研究证据包**：`python -m huidu_xingyun.cli ask --export "…"` → `outputs/evidence_<id>_<ts>.md`（含结论、路径、证据卡、覆盖说明）。
- **提交关系纠错**：回答末尾的「提交关系纠错」为馆员复核入口（当前为受控占位，不自动改图）。
- **多轮对话**：`python -m huidu_xingyun.cli repl`，支持「它/该/此…」回指上一轮实体。

## 六、边界与不做的

- 不自动修改知识图谱、不开放无限制 Text2Cypher。
- 不把全文线索自动提升为稳定关系。
- 证据不足会明确拒绝/澄清，不「一本正经地编」。
- 简化字多义词（如「人间佛教」）会触发澄清，属数据本身的歧义保护，非故障。
